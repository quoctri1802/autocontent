# Mẹ Bỉm Thông Thái Content Engine (MBTE) - Giao diện điều khiển

Giao diện điều khiển (Dashboard) cho hệ thống tự động hóa nội dung Mẹ Bỉm Thông Thái.

## Công nghệ sử dụng
- React (Vite)
- Vanilla CSS Design System (Pastel & Glassmorphism)

## Triển khai trên Vercel
- Thư mục gốc: `frontend`
- Biến môi trường: `VITE_API_URL` trỏ về Backend Render của bạn.
